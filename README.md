# Billing Data Analysis

A hands-on portfolio project that applies SQL, Excel, and Python to common billing and accounts-receivable problems: data quality, duplicate billing, AR aging, revenue reporting, and more.

Each folder is a self-contained weekly project with its own script and README. All data is **synthetic** — no real company or customer data is used.

## Projects

| Week | Project | Skills | Status |
|---|---|---|---|
| 00 | [Billing Data Quality Checks](week-00-data-quality/) | SQL (SQLite), data quality dimensions | Example |

## How to run

Most projects use SQLite. Paste a script into [sqliteonline.com](https://sqliteonline.com) or run it locally:

```bash
sqlite3 :memory: < week-00-data-quality/billing_data_quality.sql
```
